Return Policy

Pengajuan pengembalian dapat dilakukan maksimal 7 hari setelah pesanan diterima.

Ketentuan Pengembalian

Produk harus dalam kondisi asli, belum digunakan, belum dicuci, dan masih memiliki kemasan serta label produk.

How to Request a Return

Silakan hubungi LUMI melalui WhatsApp dengan menyertakan nomor pesanan dan alasan pengembalian.
